# Code of Conduct

Every PhilaCon Valley repository follows one Code of Conduct. It lives in the Community Handbook:

**[Read the PhilaCon Valley Code of Conduct](https://github.com/philaconvalley/community-handbook/blob/main/CODE_OF_CONDUCT.md)**

It applies in issues, pull requests, reviews, and discussions, the same as at our events and in
Discord.

## Report a problem

Tell any PhilaCon Valley team member, in person or on Discord. Or email
**waskar@philaconvalley.com**. You get a reply within 48 hours.

If the report is about a team member, that person takes no part in handling it. The handbook
explains the full process.

This file is a pointer, so the rules exist in one place only. To change the Code of Conduct, open an
issue in the Community Handbook.
